Skills aplicadas (regras embutidas no app)

Contatos (telefones, e-mails e nomes) vêm somente do arquivo e ficam como "Não confirmado"; o app não deduz e-mails a partir de nomes. Nomes de pessoas são dado pessoal: use só para prospecção B2B legítima. As skills do Claude não rodam dentro de uma página HTML: o app aplica as regras delas como código (qualidade cadastral, score com pesos documentados, rankings, tipo de unidade, hipóteses e próxima ação, cruzamento com benchmark). A pesquisa na web das skills Benchmark e Prospect BSA continua no Claude: gere a lista lá, exporte em Excel e importe aqui.
